# Day 94 – Multilevel Inheritance

## Topic

Multilevel Inheritance in Java

## Description

This program demonstrates multilevel inheritance using three classes: Animal, Dog, and Puppy.

## Inheritance

Animal → Dog → Puppy

## Concepts Used

* Inheritance
* extends
* Parent class
* Child class
* Multilevel inheritance

## Output

Animal eats

Dog barks

Puppy plays
